### Pulse reference implementation

| Plan item                         | Where it is shown                                                                                                       |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Engagement Rate, Creation Rate    | formulas `engaged / active × 100`, `creators / active × 100`, whole percent: 18 %, 5 %                                  |
| Interaction Index                 | formula `Engagement × 0.8 + Creation × 0.2` on the displayed rates, one decimal: 15.4                                   |
| Adoption Rate                     | formula `active / registered × 100`: 51 %                                                                               |
| PULSE Score                       | score over Interaction Index (0.3) and Adoption Rate (0.7), linear 0–100: 40.32                                         |
| Evaluation                        | five bands, marked as demo configuration (no canonical thresholds exist); the card shows "Bewertung: solide" in words   |
| Executive Health Overview         | hero score, four KPI cards, PULSE trend, explanation card - a dashboard template, published in the demo                 |
| Engagement & Participation Detail | two rate trends, active vs registered, participation by page, definitions - a dashboard template, published in the demo |

The chain reproduces the canonical numbers exactly because every derived value
is rounded to the decimals its definition declares at the moment it is
produced, and dependents consume that value ([ADR 0007](../adr/0007-derived-values-round-where-produced.md)).

## Defects found and fixed during the phase

| Defect                                                        | Impact                                                                                               | Fix                                                                                    |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| A formula on a formula, or a score on a formula, saw no input | Any chained definition was "not calculable" - Phase 3 only ever tested one level; Pulse is all chain | Derivations see the values of the ones before them, for scalars, series and breakdowns |
| The viewer ignored a dashboard's own default period           | Every dashboard opened on the last 30 days, whatever its author set                                  | Without a period in the URL, the API uses the dashboard's default; the page follows it |
| A score's evaluation band was never shown                     | Scores computed their band, but no card said what the number meant                                   | Cards carry the band as a word with a colour mark                                      |
| An unknown project id produced a server error page            | `/projects/<unknown>` crashed instead of answering "not found"                                       | The project read maps 404 to the ordinary not-found page                               |
