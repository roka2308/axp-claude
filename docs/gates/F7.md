### Share lifecycle, as the plan's build list asks

| Build item                                        | Where it is shown                                                                                                                               |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Internal sharing handoff to permissions           | "Innerhalb der Organisation" on the share page: who has access and why, a link to the object grants for tenant admins, a hint for everyone else |
| External Share object                             | `dashboard_shares`; link token and password stored as hashes only                                                                               |
| Required expiration and revoke                    | expiry required, at most 90 days, ends with the chosen day in the project time zone; revoke is immediate and deletes the share's files          |
| Configurable time/comparison/detail/export rights | all off by default; enforced by the API (403), not only hidden in the UI                                                                        |
| Optional password protection                      | Argon2id; short session cookie scoped to the share's path; five wrong attempts pause the share for 15 minutes                                   |
| Neutral unavailable page                          | unknown, revoked, expired, archived, trashed, suspended tenant, creator without access: one identical answer and one page                       |
| PDF renderer from the Presentation Model          | pdfkit, tagged, vector charts, data tables after every chart                                                                                    |
| Widget CSV                                        | from the detail view; metadata header, locale-aware, formula injection neutralised                                                              |
| Dashboard XLSX                                    | overview sheet with metadata, all key figures on one sheet, one sheet per series and table, real numbers                                        |
| Hybrid PPTX                                       | key figures, evaluations, tables and text native; line charts as PNG with alt text and values in the notes                                      |
| Protected temporary artifacts with auto-delete    | AES-256-GCM on disk, bound to the artifact id; requester-only; worker `export-artifact-cleanup` every minute                                    |

## Decisions recorded

- [ADR 0009](../adr/0009-shares-lend-access-exports-are-ephemeral.md): a share
  lends its creator's access and cannot outlive it; internal notes are dropped
  by the presentation builder for the `external` and `export` audiences; export
  files are encrypted, requester-bound and ephemeral.
- [DEV-007](../../DEVIATIONS.md): export files use the default theme until
  tenant themes exist (Phase 9).
- [DEV-008](../../DEVIATIONS.md): rendering for scheduled delivery and the PPTX
  stability gate come with Phase 8.

## Defects found and fixed during the phase

| Defect                                                        | Impact                                                                              | Fix                                                                                       |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| A time series carried no unit or decimals                     | Anything reading a chart's values - an export, a data table - could not format them | Series content carries each series' unit and decimals, like table columns now do          |
| Dashboard authorization mapped every non-read right to `edit` | A viewer allowed to export would have needed an edit grant                          | One shared `scopeForDashboard`: read, export and share need `view`; drafting needs `edit` |
| The detail view's export action said "arrives with Phase 7"   | -                                                                                   | It is now a real control, available where the caller may export and the widget has data   |
