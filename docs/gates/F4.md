## Decisions recorded

[ADR 0005](../adr/0005-widgets-stream-independently.md): the viewer asks for
the layout first and for each widget separately, each tile streaming in behind
its own Suspense boundary. The one-request presentation route stays, because
exports must not depend on a browser rendering anything.

**The state fixture uses reserved mock metrics.** A dashboard reads one site,
so the state cannot vary per scenario; it has to vary per metric. The mock
adapter recognises seven `mock_state_*` source metrics, each standing for a
real Matomo situation (a report the site does not collect, an unreadable value,
a partly processed day, a report answering 503). The fixture reaches them
through ordinary `native_metric` source bindings, so nothing above the
connector knows the fixture exists. `missing` and `not_applicable` come from
the product itself — an unmapped requirement, a widget without a metric.

**Search is a basic index by design.** Names are already in MySQL, the
candidate set is small, and a separate index would be one more store to keep
consistent with the permission model. Search and the library share one
definition of "may open", so they cannot disagree.

## Defects found and fixed during the phase

| Defect                                                                         | Impact                                                                                                                                                                                       | Fix                                                                                                                |
| ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `unknown`, `not_tracked` and `not_applicable` values produced a `ready` widget | A card whose only value was unreadable showed a blank number — the silent gap D10 exists to prevent                                                                                          | `deriveWidgetState` takes an absence state when every value shares it; the reason travels as `stateMessage`        |
| Message keys containing a dot were unreachable                                 | next-intl reads a dot as nesting, so `widget.no_metric_configured.action` and three siblings never rendered since Phase 1 — the lookups were guarded with `t.has()` and simply stayed silent | Keys renamed; `messages.test.ts` fails on any dotted key and resolves every key the server sends in both languages |
| That test found a fourth, older gap                                            | `auth.current_password_invalid` had no text in either language                                                                                                                               | Written                                                                                                            |
| `SCHEMA_VERSION` stood at `1` through three migrations                         | The footer claimed schema 1 against a schema-4 database                                                                                                                                      | Now the migration count, with a test against the journal                                                           |
| Home still announced "Phase 0" as the current state                            | The first screen after sign-in described a product that no longer exists                                                                                                                     | Home lists the caller's dashboards                                                                                 |
| Widget data-quality notes were always empty                                    | A `warning` could not say what the warning was                                                                                                                                               | Notes are collected from the values that carry them, de-duplicated across points                                   |
