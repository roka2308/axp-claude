## Decisions recorded

[ADR 0004](../adr/0004-grid-resolves-overlaps-without-compacting.md): the grid
resolves overlaps but never compacts a layout upwards. D2 requires "no
overlaps"; "no gaps" is a different rule and not the user's. Worth recording
because the Emergent track may well decide otherwise by adopting a grid library
whose default is springy.

The grid engine moved from `@axp/core` into `@axp/contracts` during this phase.
The editor needs it in the browser, the web app may not import the domain layer,
and the raster rules are part of what both tracks implement — so the shared
vocabulary package is where they belong.

## Defects found and fixed during the phase

| Defect                                                             | Impact                                                                                                                                                       | Fix                                                                                                                        |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| New audit actions were never recorded                              | `action` is a MySQL enum and the audit service swallows write failures on purpose, so `dashboard.editor_takeover` and `dashboard.restored` vanished silently | Migration 0002 extends the enum; `persistence-rules.test.ts` now asserts the column and the contract list the same actions |
| Keyboard focus did not select a widget                             | A keyboard user could move a widget but never see its settings — the Inspector only followed the pointer                                                     | Selection follows focus                                                                                                    |
| Turbopack could not resolve a value import inside `@axp/contracts` | The web build failed once the grid engine imported values rather than types; type-only imports are erased and had hidden it                                  | Extensionless relative import, matching the rest of the repository                                                         |
| The project listing showed the draft name of a published dashboard | Renaming a draft renamed what every viewer saw in the list - the same leak the presentation path is careful to avoid                                         | The listing reports the published name once there is one; the draft name only before the first publish                     |
