# Canonical fixture data

`demo_seed.json` is copied verbatim from the Version D handoff package
(`analytics_experience_version_d_v1.0/fixtures/demo_seed.json`).

Both implementation tracks - Claude Code and Emergent - seed from the same
values, so the comparison gates compare behaviour rather than data. Do not edit
this file to make an implementation pass; change the handoff fixture and copy it
again, or record a deviation.

Derived Pulse values, weights and portable ids are documented in
`06_Canonical_Demo_Data_Pulse_v1.0.md`.
